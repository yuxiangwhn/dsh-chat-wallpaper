# dsh-chat-wallpaper

One picture behind the DeepSeek Harness chat UI — and the surfaces in front of it
rebuilt as glass, so the picture shows through instead of being covered.

[中文](README.zh.md)

![The bundled default picture](assets/wallpaper-preview.jpg)

## What it does

- **Wallpaper layer.** A fixed image layer sits behind the whole shell; the app's
  background tokens are repointed at translucent tints so the frame, sidebar and
  content column all let the picture through.
- **Glass surfaces.** The composer card, the user's own message bubbles and the
  new-chat button get a frosted treatment (blur + tint + a 1px inner ring), so
  they read as material in front of the wallpaper rather than flat boxes.
- **Blur follows the conversation.** An empty new conversation shows the
  wallpaper at exactly the slider's blur. As soon as the composer has text — or
  the conversation already has messages — 5px is added on top, with a 0.45s
  transition, and it stays after the message is sent.
- **Settings-style windows frost the backdrop.** When a stacked window opens
  (settings, plugin market, pairing dialog…), the background is frosted instantly
  and the window in front keeps its own crisp pixels; closing it restores the
  sharp picture immediately. In-composer popups such as the `/` command palette
  are not treated as windows and never freeze the background.
- **Your own picture.** The panel's *选择图片…* button stores any local image in
  IndexedDB (per browser profile, never uploaded). *默认* restores the bundled
  picture.
- **Controls in the sidebar footer.** A small button next to the sidebar's
  utility icons opens the sliders, so nothing is added to Settings.

## Install

```
dsh plugin add dsh-chat-wallpaper
```

Not on npm yet — install the prebuilt tarball instead:

```
dsh plugin add https://github.com/yuxiangwhn/dsh-chat-wallpaper/releases/download/v1.1.1/dsh-chat-wallpaper-1.1.1.tgz
```

Or from the plugin market in DSH (Plugins → discover/search `dsh-chat-wallpaper`)
once the entry is listed.

## Controls

| Control | Range | What it changes |
| --- | --- | --- |
| 亮度 / Brightness | 50–220% | brightness filter on the wallpaper layer |
| 透明度 / Opacity | 15–100% | opacity of the wallpaper layer |
| 磨砂 / Blur | 0–24px | base blur of the wallpaper layer |
| 面板 / Panel | 15–98% | opacity of the shell tints (content, sidebar, panels) |
| 图片 / Image | — | pick a local image, or restore the bundled default |
| 重置 / Reset | — | back to the defaults |

Settings are stored in `localStorage` under `dsh-chat-wallpaper:settings:v1`; a
picked image lives in IndexedDB (`dsh-chat-wallpaper`).

## Compatibility

Developed and verified on the DSH desktop window (Windows, DSH `0.2.2-rc.1`).
The browser (Web) surface is supported by the same code paths; macOS uses the
`darwin` frame rules the shell publishes.

## Privacy

The plugin makes no network requests and has no host-side code or storage. The
bundled default picture is generated by `scripts/make-wallpaper.py`; an image you
pick stays in this browser profile's IndexedDB.

## Known limits

- The glass treatment targets the shell's current DOM: the composer card, the
  user-bubble rows and the sidebar footer. A large host update that renames those
  components can leave parts of the UI untreated until the selectors are updated.
- The wallpaper is one fixed layer: very wide or multi-monitor setups show it
  scaled to cover the window, not tiled per screen.
- Blur and transparency are CSS effects on the page; they do not affect the
  window's own drop shadow or the OS title bar.

## Development

```
python build_client.py                 # client.src.js -> lib/client.js, embeds assets/wall.jpg
python scripts/make-wallpaper.py       # regenerate the bundled default picture
```

`client.src.js` is the readable source; `lib/client.js` is what DSH loads and
contains the image as a data URL (the desktop shell answers file-looking
`dsh-app://` paths itself, so the picture cannot be fetched as a URL).
